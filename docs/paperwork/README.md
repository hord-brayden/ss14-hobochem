# Cooper & Cooper — Official Firm Paperwork

Paste-ready documents for SS14 paper. Write on any blank paper (or send via fax)
and the game renders the formatting. Uses only the tags documented in the in-game
Writing guidebook: `[head]`, `[bold]`, `[italic]`, `[bolditalic]`, `[color]`, `[bullet/]`.
Block-glyph logos follow the same technique as the game's own shipped Syndicate letterhead.

| File | What it is |
| --- | --- |
| `cletus-letterhead.txt` | The firm masthead + dual NT/Syndicate endorsement bar — prepend to any document |
| `cletus-business-card.txt` | The business card: practice areas, selected verdicts, fees |
| `cletus-intake-form.txt` | Form CC-1, Emergency Client Intake — fax it to whoever's in the brig |

Stamps (notary, CentComm, clown) layer on top in-game for extra authenticity.
